# Guia Semanal Musa

Site estatico pessoal para acompanhar treino, corrida, alimentacao e evolucao semanal da Musa.

## Objetivos

- Reduzir de 57 kg para 53 kg.
- Correr 5 km ate outubro.
- Fortalecer e definir sem foco em aumento de volume muscular.
- Manter aerobico diario, musculacao/funcional e corrida 3x por semana.

## Como usar

- Abra `index.html` ou publique no GitHub Pages.
- Registre peso, medidas, treino feito e alimentacao.
- Use `Exportar JSON` no fim da semana para salvar os dados e ajustar o plano seguinte.

## Observacao sobre suplementos

As sugestoes sao gerais e conservadoras. Termogenicos agressivos, manipulados e estimulantes devem ser avaliados com medico/nutricionista, especialmente se houver ansiedade, pressao alta, arritmia, gastrite, uso de medicamentos ou alteracoes no sono.
